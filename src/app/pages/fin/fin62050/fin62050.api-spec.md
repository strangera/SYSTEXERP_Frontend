## 二、Request

### 後端 C# DTO

```csharp
// FIN62050Request.cs
public class queryFIN62050Request
{
    [Required]
    public DateTime StartDate { get; set; }         // 查詢日期起（必填）

    [Required]
    public DateTime EndDate { get; set; }           // 查詢日期迄（必填）

    public bool ShowUnCheckYN { get; set; } = true; // 是否顯示應兌未兌票據，預設 true

    public List<string>? BankList { get; set; }     // 銀行代號清單（null = 全部）
}
```

SP 呼叫對應：
- `@StartDate`    ← `StartDate`
- `@EndDate`      ← `EndDate`
- `@ShowUnCheckYN` ← `ShowUnCheckYN ? "Y" : "N"`
- `@BankList`     ← `BankList != null && BankList.Any() ? string.Join(',', BankList) : null`

## 三、Response

### RowType 推導規則（後端從 SP 輸出欄位推導，不依賴 SP 直接輸出 RowType）

| RowType | 說明 | 判斷條件 |
|---|---|---|
| `INIT` | 期初餘額 | `NoteDesc == "期初餘額"` |
| `D`    | 存款簿明細 | `CHK_No == null` 且不符合其他合計列 |
| `A`    | 存款簿〔A〕合計 | `NoteDesc == "存款簿金額〔A〕合計"` |
| `UD`   | 應付未兌現票據明細 | `CHK_No != null` |
| `B`    | 應兌未兌票據〔B〕合計 | `NoteDesc == "應兌未兌票據金額〔B〕合計"` |
| `C`    | 支存帳上金額 | `NoteDesc != null && NoteDesc.StartsWith("支存帳上金額")` |

### 後端 C# DTO

## 四、前端渲染方式

### 問題
- A 區（存款簿明細）欄位：日期 | 說明 | 借方金額 | 貸方金額 | 餘額
- B 區（應兌未兌票據）欄位：到期日 | 票據號碼 | 廠商代號 | 廠商名稱 | 票據狀態 | 貸方金額
- 兩區欄位不同 → 無法用單一 `app-table-report` 呈現

### 方案：自訂模板（fin62050.component.html 內實作）
- 不建立新的 shared 元件
- 在頁面 HTML 以 `@for` 按 `BNK_id` 分組
- 每個銀行 section 內：
  1. 銀行標題列（BNK_AccName）
  2. 期初餘額列（INIT）
  3. A 區表頭 + D 列明細
  4. A 合計列（RowType = 'A'，粗體）
  5. B 區表頭 + UD 列明細（ShowUnCheckYN = true 時顯示）
  6. B 合計列（RowType = 'B'，粗體）
  7. 支存帳上金額列（RowType = 'C'，粗體）

### 資料前處理（component.ts 中做，避免 template 過肥）
```typescript
// 查詢結果分組
bankGroups: Map<string, FIN62050ResponseItem[]> = new Map();

private groupByBank(items: FIN62050ResponseItem[]): Map<string, FIN62050ResponseItem[]> {
  const map = new Map<string, FIN62050ResponseItem[]>();
  for (const item of items) {
    if (!map.has(item.BNK_id)) map.set(item.BNK_id, []);
    map.get(item.BNK_id)!.push(item);
  }
  return map;
}
```

## 五、銀行下拉

- 使用 `DropdownApiService.queryAps1002ForBankFilter()`（`/queryAPS1002_DropDownList`）
- `value = BNK_id`（GL 科目代號，如 '110301'），`label = ACCCNAME`
- `BNK_id` ≠ `BNK_No`（不同欄位）；SP `@BankList` 需要 `BNK_id`
- 已在後端 SQL 加 `A.BNK_id`、C# model 加 `BNK_id` 屬性、TypeScript `Aps1002Item` 加 `BNK_id: string`、service 新增 `queryAps1002ForBankFilter()` 方法
