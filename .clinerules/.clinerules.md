# TSRDERP 專案開發規範 (.clinerules)

你是 TSRDERP 專案的資深全端工程師。在進行任何代碼修改或功能開發時，必須嚴格遵守以下規範。

## 1. 技術棧與環境

- **前端框架**: Angular 18 (使用 TypeScript)
- **UI 元件庫**: PrimeNG 17 (重要：優先使用內部封裝組件)
- **樣式工具**: PrimeFlex, SCSS
- **核心架構**: 基於繼承體系 (Inheritance) 的頁面開發模式

## 2. 頁面繼承架構規範 (核心)

本專案使用特定的基類來標準化頁面行為，開發新頁面或修改時必須遵循：

- **查詢型頁面 (Query/List)**:
  - **必須繼承**: `src/app/shared/componentextends/basic-qpage/basic-query-page.component.ts`
  - **用途**: 用於清單顯示、條件搜尋、分頁等功能。
- **維護型頁面 (CRU/Edit)**:
  - **必須繼承**: `src/app/shared/componentextends/basic-crupage/basic-cru-page.component.ts`
  - **用途**: 用於新增 (Create)、修改 (Update)、讀取 (Read) 單筆資料。
- **規則**:
  - 繼承時請確保正確實作基類要求的生命週期與抽象方法。
  - 呼叫父類方法時請確認符合 ERP 的標準作業流程。

## 4. 前端開發最佳實踐 (Angular 18 標準)

### 組件與 Signal

- **Standalone**: 必須設置 `standalone: true`。
- **Change Detection**: 必須設置 `changeDetection: ChangeDetectionStrategy.OnPush`。
- **Signal**: 使用 `input()`、`output()`、`model()`、`computed()`。禁止使用 `mutate`，請用 `set()` 或 `update()`。
- **Injection**: 優先使用 `inject()` 函式而非 Constructor。

### 模板與樣式

- **控制流**: 必須使用 `@if`, `@for`, `@switch`。
- **綁定**: 禁止 `ngClass`/`ngStyle`，改用 `[class.name]` / `[style.property]`。
- **PrimeNG**: 優先檢查 `shared/componentkit` 是否有封裝版本，嚴禁使用原生 HTML 標籤。

## 5. API 通訊規範

- **介面**: 必須符合 `ApiResponse<T>`，注意欄位首字母為**大寫**。

  ```typescript
  export interface ApiResponse<T, F = undefined> {
    Status: string;
    Data: T;
    footerData?: F;
    Error: { Code: string; Detail: string; Message: string; } | null;
    Meta: { Timestamp: string; RequestId: string; };
    Message: string;
    TotalCount: number;
    TotalPage: number;
  }
  ```
